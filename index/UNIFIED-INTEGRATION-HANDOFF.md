### What the director sees (one flow, no new tab)
- **Fit check** (collapsed `Fit check · N conflicts · N unknown` under the frame picker). Rows are built only from supplied fields, each with its source: image similarity is labelled "not a fit score"; availability follows the CoStar status (the legacy boolean never counts); vehicles use the source's sufficiency flag and unknown capacity stays unknown; numbers written in the script count only as "at least N m²/ft²/ceiling" lower bounds compared with index estimates (estimates stay "consistent (estimated)", never "matches"); "quiet" is never inferred from an empty noise screen; windows/doors/islands etc. are listed as "not in the data, judged only by image similarity". No percentages, no overall suitability.
- **Try another location** (collapsed list under the frame picker, one thumbnail per other eligible property in the current candidate pool, max 6; empty-state text when none). One click swaps; both takes, durations, dialogue, stand-ins and the authored-sample origin are copied to the new exact frame as a **draft flagged unreviewed**: a notice says the previous scan identity does not apply and fit stays uncalibrated until "Staging looks right on this frame". Until then PNG, compare, WebM frames and the shoot pack carry "STAGING CARRIED OVER · UNREVIEWED ON THIS FRAME". Undo swap and Back to planned location never delete staging (edits stay with their frame). Plan summary says "location swapped by hand, totals not recalculated"; exports null the plan totals and add a note. A rejected property is invalid immediately (even before the replan returns) and a new plan clears hand swaps.
- **Production decision sheet** inside the existing Shoot pack (no new export): per scene, selected property/frame and swap status, both takes (the image shows the active take), fit evidence, continuity notes, the user's dressing notes (never generated; Typecast suggests none), and an on-site checklist derived only from unresolved items plus a generic measure-on-site line. It states it contains no prices, permissions, owner contact or feasibility. Print CSS added; verified by rendering the saved pack in Chromium print mode (screenshot and a 312 KB PDF).
- **Continuity** is silent by default. Only scenes the user gives the same short "Continuity link" tag (Shot panel, "Production notes", collapsed) are compared, consecutive members only: different properties = "Mismatch" (from the user's link), same property but different frames = "cannot compare", day/night words differ = "Possible mismatch", an actor ending/starting more than 0.15 apart = "Possible mismatch" only when both scenes use the same exact frame and the actor name matches. Each note has a corrective action; nothing is blocked or rewritten; the scene rail shows "continuity note" only when there is one.
